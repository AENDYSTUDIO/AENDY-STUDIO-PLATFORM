# 🎵 MusicStream - Децентрализованная музыкальная платформа

MusicStream - это современная музыкальная стриминговая платформа, вдохновленная Audius, построенная на Next.js 15 с использованием передовых технологий. Платформа включает в себя систему вознаграждений с токенами SAUDIO, загрузку музыки, управление плейлистами и социальные функции.

## ✨ Технологический стек

### 🎯 Основной фреймворк
- **⚡ Next.js 15** - React фреймворк с App Router
- **📘 TypeScript 5** - Типобезопасный JavaScript
- **🎨 Tailwind CSS 4** - Утилитарный CSS фреймворк
- **🧩 shadcn/ui** - Доступные компоненты на Radix UI

### 🗄️ База данных и бэкенд
- **🗄️ Prisma** - ORM для работы с базой данных
- **🔐 SQLite** - Легковесная база данных для разработки
- **🔄 Zustand** - Управление состоянием
- **🌐 TanStack Query** - Управление данными

### 🎵 Музыкальные функции
- **🎵 HTML5 Audio** - Воспроизведение музыки
- **📊 Прогресс-бары** - Отслеживание воспроизведения
- **🎚️ Управление громкостью** - Контроль звука
- **🔁 Повтор и перемешивание** - Функции плеера

### 🎨 UI/UX компоненты
- **🎯 Lucide React** - Иконки
- **🌈 Framer Motion** - Анимации
- **📱 Адаптивный дизайн** - Mobile-first подход
- **🌓 Темная/светлая тема** - Переключение тем

## 🗄️ Схема базы данных

### Пользователи (User)
- Базовая информация (email, имя, аватар)
- Премиум статус
- Связи с треками, плейлистами, лайками

### Треки (Track)
- Метаданные (название, исполнитель, альбом, жанр)
- Длительность и количество прослушиваний
- Ссылки на файлы и обложки

### Плейлисты (Playlist)
- Название, описание, публичность
- Связи с треками через промежуточную таблицу

### Лайки (Like)
- Лайки для треков и плейлистов
- Типизация для разных сущностей

### Комментарии (Comment)
- Комментарии к трекам и плейлистам
- Связи с пользователями

### Награды (Reward)
- Типы наград (стрим, загрузка, плейлист и т.д.)
- Значения и статус получения

### Токены (Token)
- Баланс SAUDIO
- История транзакций

### Сообщения (Message)
- Система обмена сообщениями
- Отправитель и получатель

## 🎯 API Эндпоинты

### Аутентификация
- `POST /api/auth/register` - Регистрация пользователя
- `POST /api/auth/login` - Вход пользователя

### Треки
- `POST /api/tracks` - Создание нового трека
- `GET /api/tracks` - Получение списка треков
- `GET /api/tracks?trending=true` - Трендовые треки

### Плейлисты
- `POST /api/playlists` - Создание плейлиста
- `GET /api/playlists` - Получение плейлистов
- `GET /api/playlists?userId=...` - Плейлисты пользователя

### Профили
- `GET /api/profile?userId=...` - Получение профиля
- `PUT /api/profile` - Обновление профиля
